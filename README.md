# Swarma-lemma

Swarma-lemma is an independent Go module for recording product requirements, decisions, evidence, and their dependencies as an auditable knowledge graph. It is intended to preserve old versions, show what is current, and make the effect of a changed requirement visible. The module will include a command-line and JSON interface and its own agent skill.

## Status

Research and design. Production implementation, a Go module, a CLI, and an agent skill do not exist yet.

## Build, test, and run

There are no product build, test, or run commands at this stage. Go version and implementation details remain to be selected during design.
